# Estructura según el tipo de libro

Todos los libros empiezan igual (portada → índice → introducción de 1–3 páginas) y terminan
igual (cierre o epílogo → fuentes → contraportada). Entre medio, la estructura cambia.
Son puntos de partida: adapta el número de capítulos al contenido.

**El tipo lo decide el contenido, no el tema.** Una investigación sobre un hallazgo es
`research`; si cuenta cómo se llegó a algo con el tiempo, `story`; si enseña a hacer algo,
`manual`; si aclara un concepto, `explainer`; si ayuda a entender un campo y decidir, `guide`.
Si no encaja en ninguno, `other`, con la estructura que mejor cuente lo investigado.

Cuando la fuente es una investigación hecha en la conversación, el libro la cubre completa: cada
hallazgo importante tiene su página, y nada se añade sin fuente.

Tamaño orientativo: 30–70 páginas. Más de 80 suele significar que son dos libros.

## Guía (`guide`)
Para entender un tema y saber tomar decisiones.
1. **Principios:** las 2–4 ideas que lo explican todo.
2. **Las piezas:** cada concepto importante, una página o dos cada uno (pregunta → definición → ejemplo).
3. **Cómo se combinan:** diagramas `combine`, "cuándo usar qué".
4. **En la práctica:** casos concretos y errores comunes (`myths`).
5. **Práctica:** ejercicios o pasos para aplicarlo.

## Manual (`manual`)
Para hacer algo concreto sin perderse.
1. **Antes de empezar:** qué necesitas, cuánto tarda, qué obtendrás.
2. **Fases** (un capítulo cada una): pasos numerados con `list` ordenada (`start` para continuar la numeración entre páginas), una `note` "Ojo:" con el error típico y una página de "Sabrás que funcionó cuando…".
3. **Si algo falla:** problemas frecuentes y su solución (`table` de síntoma → arreglo).
4. **Siguientes pasos.**

## Historia (`story`)
Para seguir un hilo de hechos o un relato y recordarlo.
1. **El mundo antes:** contexto en pocas páginas.
2. **Actos o épocas** (un capítulo cada uno): una escena por página, con fecha, lugar y personas. Usa `list` ordenada como línea de tiempo y `sizes` o `columns` para comparar antes/después.
3. **El giro:** el momento clave, con un `highlight`.
4. **Lo que dejó:** consecuencias y por qué importa hoy.
- Si es ficción o reconstrucción, dilo en la introducción.

## Explicación (`explainer`)
Para que una idea difícil se entienda de verdad.
1. **La pregunta:** qué vamos a entender y por qué cuesta.
2. **Las piezas mínimas:** solo los conceptos necesarios.
3. **El mecanismo:** cómo funciona, paso a paso, con un diagrama por paso.
4. **Analogías y ejemplos.**
5. **Errores comunes** (`myths`).
6. **En una frase:** una página final que lo resume todo.

## Investigación (`research`)
Para contar un hallazgo, un estudio o el resultado de investigar algo.
1. **El hallazgo,** primero y en una frase.
2. **Cómo se sabe:** método, datos, fuentes.
3. **Qué significa** y qué no significa.
4. **Preguntas abiertas.**

## Otro (`other`)
Para lo que no encaja arriba: una comparación, un resumen de un libro o curso, un informe, unas
memorias. Elige capítulos que sigan el orden natural del contenido y usa los bloques que mejor lo
muestren. Inicio y final, como en todos los libros.
