# Changelog

## 1.0.0
- First public release of Bookify.
- Standard `SKILL.md` skill, installed with one command in Claude Code, Command Code, OpenCode and GitHub Copilot (VS Code).
- Turns the research in the conversation, or any topic, into an HTML book with page turning.
- Books in the user's language (reader UI in Spanish, English and Portuguese; others through `ui`).
- `update` looks for a new GitHub release and updates every installation.
